# Scripts en Bash, Python y PowerShell

En este repositorio voy a ir guardando scripts realizados en Python, Bash y PowerShell.

## 🛠️ Tecnologías que usaré

- Bash
- Python 3
- PowerShell 5.1
- Docker (sólo en el caso de algunos scripts)

## 🚀 Uso

Cada script se ejecuta de manera independiente. Por ejemplo:

```bash
cd monitorizacion-espacio-disco
./monitorizacion_espacio.sh

cd comprobacion-estado-servicios
python3 health_check.py

cd consultar-servicios-windows
.\consultar-servicios-windows.ps1
```
